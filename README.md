# SorTirowka 📁

**SorTirowka** — это простая утилита на Python для автоматической сортировки файлов из папки «Загрузки» по категориям (Видео, Картинки, Аудио, Документы, Архивы, Код и т.д.).

## 🚀 Возможности
- Автоматически определяет папку загрузок (Linux, macOS, Windows).
- Поддерживает более 100 расширений файлов.
- Не затирает файлы с одинаковыми именами (добавляет `(1)`, `(2)` и т.д.).
- Обрабатывает ошибки (если файл занят или нет прав).
- Выводит красивую статистику после завершения работы.

## 🛠️ Как запустить
1. Установи Python 3.
2. Запусти в терминале:
   ```bash
   python sortirowka.py
